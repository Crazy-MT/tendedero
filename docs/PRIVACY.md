# 晾贴 / PegNest 隐私说明

2026-10-11

晾贴是本机截图与剪贴板历史工具。它无需账号，不使用统计分析、广告跟踪、开发者服务器或云端历史同步。应用未申请网络访问权限。

记录剪贴板需由用户主动开启，默认关闭。开启后保存复制的文字、链接和图片，从下一次复制开始。默认最多保留 100 个混合条目，可改变上限。暂停后不采集新复制。文件复制和多个内容项目不保存，富文本以纯文字保存。单条文字上限为 1 MiB UTF-8；图片输入和保存输出最多 64 MiB，尺寸最多 80,000,000 像素。

应用检查 ConcealedType、TransientType、AutoGeneratedType 隐私标记并跳过相应复制。标记依赖复制来源，应用不能识别所有密码或敏感内容。未标记的密码可能被保存，请在复制敏感内容前暂停记录。日志不包含剪贴板内容、来源应用或文件全路径。

历史副本和索引保存在应用的本机沙盒内。删除、清空或自动淘汰私有副本会从应用存储删除，不移至系统废纸篓。文件删除并不构成磁盘安全擦除；系统备份可能有历史副本。清空历史不清空系统当前剪贴板。

截图目录经系统选择窗口授权，应用保存 security-scoped bookmarks 在后续启动恢复访问。目录内新图片和录屏可显示于挂绳。取下外部截图和容量淘汰只移除应用引用，不删除原件；「移到废纸篓」是独立的用户操作。导出经系统保存窗口授权，导出副本不会移走历史原文件。

点击卡片会将内容写回系统剪贴板。macOS 通用剪贴板可能按用户的系统设置跨设备同步当前剪贴板；晾贴没有实现自己的跨设备同步。

此文件描述当前实现的数据行为。对外发布前需要由实际运营主体提供支持联系方式和可访问的隐私政策页面，不得将不存在的联系方式或未发布的 URL 用于商店资料。
