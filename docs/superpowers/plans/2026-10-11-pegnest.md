# 晾贴 / PegNest Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在现有截图挂绳上实现可恢复的本机剪贴板历史，使用独立品牌，并交付可验证的 Mac App Store 沙盒工程。

**Architecture:** 复用 Line、Pegged 和现有挂绳动画。新增 HistoryStore 管理私有副本与索引，FolderAccess 管理用户授权目录，ClipboardWatcher 只负责读取与过滤，再由 Line 统一更新卡片。先验证数据与权限，再连接界面，最后做品牌和商店打包。

**Tech Stack:** Swift、AppKit、SwiftUI、Foundation、CryptoKit、XCTest、Xcode；无新增第三方运行时依赖。

**Spec:** `docs/superpowers/specs/2026-10-11-pegnest-design.md`（用户已于本轮批准）

## Global Constraints

- macOS 14 起兼容；Apple silicon 和 Intel 通用构建。
- 中文品牌「晾贴」、英文品牌「PegNest」；名称可用性与商标状态须另行实查。
- 默认关闭剪贴板采集；默认保留 100 个混合条目，保留 25/50/100 和按屏幕容量选项。
- 单条文字上限 1 MiB UTF-8；图片输入、输出上限 64 MiB，像素上限 80,000,000。
- 所有 item 的 ConcealedType、TransientType、AutoGeneratedType 标记均导致整次采集跳过；文件复制不采集。
- 本地原子保存，私有文件权限 0600；不记录剪贴板内容、来源应用或文件全路径。
- 私有副本删除不经过废纸篓；外部截图取下和自动淘汰均保留原件。
- App Sandbox、用户选择文件读写、app-scoped bookmarks；不开网络、Apple Events、辅助功能或屏幕录制权限。
- 不使用原名称、图标及 docs 美术作为新产品素材；保留原 MIT 版权许可和准确上游致谢。
- 不虚构开发者主体、联系信息、签名、商店状态或已完成的验收。

## Review Focus

1. 同一复制中多个项目或图片附带文字：先检查全部隐私标记，只记录一项明确的文字或图片，避免文件图标误采。Task 1/2 测试固定行为。
2. 暂停后恢复时旧异步图片任务返回：使用采集 generation 与 changeCount 双重校验，旧任务不能写入。Task 2 测试。
3. 目录书签失效、目录移动或 symlink 指向授权范围外：只恢复有效授权，路径检查解析 symlink；失败有重新授权入口。Task 1/3 测试。
4. 磁盘写入失败或崩溃遗留文件：保存失败不添加卡片，清理仅针对私有目录内本应用管理的文件，不删外部原件。Task 1 测试。
5. 删除、清空或导出时卡片动画未完成：逻辑索引先更新，失败保留可操作条目，导出不移走原文件。Task 1/4 测试。

### Task 2: 剪贴板采集与隐私边界

**Files:** Modify `Sources/PegNest/ClipboardWatcher.swift`; create `Sources/PegNest/ClipboardPolicy.swift`, `Tests/PegNestTests/ClipboardWatcherTests.swift`, `Tests/PegNestTests/ClipboardPolicyTests.swift`.

**Interfaces:**
- 消费 Task 1 的 `ClipboardContent`，不直接写文件。
- `ClipboardPolicy.accepts(types: [[NSPasteboard.PasteboardType]]) -> Bool`：任何私有标记或文件 URL 则 false，多个普通内容项目也跳过，避免不完整采集。
- `ClipboardPolicy.text(_ value: String) -> String?`：不超过 1 MiB，非全空白，返回未修改原文。
- `ClipboardPolicy.png(from: Data, type: NSPasteboard.PasteboardType) -> Data?`：ImageIO 先查尺寸再解码，限制输入/输出和像素。
- `ClipboardWatcher.init(pasteboard: NSPasteboard = .general, onContent: @escaping (ClipboardContent) -> Void)`；`start()`、`stop()`、内部 `check()` 可供 @testable 测试。
- 内部 `acceptDecoded(_ content: ClipboardContent, count: Int, generation: Int)` 校验 timer 状态、generation 和 changeCount，支持确定性异步过期测试。

- [ ] 写 `testPrivateMarkerOnAnyItemRejectsWholeCopy`，逐一覆盖三个标记、普通项目混合隐私项目、文件 URL 和多项目。
- [ ] 写 `testTextBoundsAndWhitespace`：正好 1 MiB 接收，超出一个字节拒绝，中文按 UTF-8 字节，原换行保留，全空白跳过。
- [ ] 写 `testImageValidationRejectsMalformedAndOversizedData`：无效数据、过大输入、过大尺寸拒绝，小 PNG/TIFF 接收为 PNG。
- [ ] 写 `testStartDoesNotCaptureExistingClipboard`、`testStopRejectsDelayedDecodeAfterRestart`、`testChangeCountRejectsStaleDecode`，使用命名测试 pasteboard，不接触真实剪贴板。
