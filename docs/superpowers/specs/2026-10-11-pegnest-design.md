# 晾贴 / PegNest 第一版设计

日期：2026-10-11。用户已经确认功能和品牌方向；本文件将该方向落实为可审核的实现边界。

## 目标与验收

将当前截图晾衣绳扩展为本机截图与剪贴板历史工具，完成独立品牌，并准备可提交 Mac App Store 的沙盒工程。保留 macOS 14 起的兼容性，使用 Swift、AppKit、SwiftUI 和系统框架，不增加第三方运行时依赖。

核心验收是实际运行的桌面应用：复制中文、英文、多行文本、链接及图片后出现相应挂绳卡片；点击恢复完整内容，重复使用不产生新记录；滚动可访问旧条目；删除、清空、暂停和重启恢复有效；用户授权的截图目录在重启后仍可监听。最终商店状态必须根据 App Store Connect 实际反馈报告，不能将本机构建成功当作已上架。

## 功能和数据流

### 剪贴板采集

沿用 ClipboardWatcher 的 changeCount 轮询，每 0.5 秒检查一次。默认关闭，首次开启时说明记录内容、保留上限、本地存储和暂停/清空入口；停止后不读取内容，再次启动只处理启动后的变化，不补采当前旧剪贴板。

采集文字（链接以原文文字保存）和图片。文件复制不采集，不增加文件历史、富文本格式保留、OCR、云同步或跨应用自动粘贴。文字复制时仍保留原来的换行和空格。文字预览可截断，存储和重新复制不能截断。空白内容跳过。单条文字上限 1 MiB UTF-8；图片沿用 64 MiB 输入和 80,000,000 像素上限，并对输出再次检查大小。

采集前检查所有 pasteboard item 的隐私类型：ConcealedType、TransientType、AutoGeneratedType，任何一项存在则整次复制跳过。应用自己的重新复制带 AutoGeneratedType 标记，防止回采。不能保证识别未标记的密码，首次提示与隐私政策必须准确说明这一限制。整个流程不得记录内容、来源应用、文件全路径或原始剪贴板到日志。

读取期间 changeCount 变化则放弃旧采集。异步图片解码在后台执行，回到主线程时再次检查 changeCount 及采集仍启用，暂停后不接收未完成的任务。

### 条目、容量与持久化

扩展 Line/Pegged 现有模型区分文字和媒体，复用挂绳、夹子、摇摆、滚动和复制反馈。文字存为应用私有目录中的 UTF-8 文件，图片存 PNG，媒体保留现有文件引用。文字卡片使用独立便签布局，可显示文本/链接类型标记。

默认保留最近 100 个混合条目。保留现有 25/50/100 容量选项，选择「按屏幕容纳数量」也必须明确其较短的保留行为；首次默认值为 100。重复的采集内容复用已有条目并移至最新位置；主动点击历史只复制，不改变历史。达到容量时淘汰最老条目，删除应用私有副本；外部截图原件不删除。

恢复持久化索引时校验条目仍存在、类型有效、路径位于应用私有目录或已授权目录，不加载任意 UserDefaults 路径。容量限制在启动恢复时也执行。保存失败需反馈错误，不显示成功卡片；写入采用原子操作，私有文件权限为 0600。启动清理无索引的应用私有历史文件，避免崩溃留下无限增长的副本。

删除和清空历史永久删除应用私有副本，不将敏感文字和图片移到系统废纸篓。外部截图「从挂绳取下」仅移除引用；显式「移到废纸篓」继续作为独立用户操作。清空历史不修改系统当前剪贴板。

### 卡片操作

- 单击：复制完整文字，或原图片/媒体；展示成功反馈，写入失败则提示失败。
- 文字双击或长按：打开可选择、可滚动的完整文本预览，不调用图片标注。
- 图片：保留预览、复制和拖拽；文字拖拽传递文本，导出文件使用保存面板。
- 每条支持移除，菜单支持清空全部；容量超出屏幕时保留现有滚动访问。
- 中英文菜单、首次提示和空状态都覆盖截图与文字；基本 VoiceOver 标签能说明内容类型、预览和操作。

## Mac App Store 改造

### 文件权限

启用 App Sandbox、用户选择文件读写和 app-scoped bookmarks。不开网络、Apple Events、辅助功能或屏幕录制权限。

删除 Inbox 对 com.apple.screencapture 的跨应用偏好修改及退出恢复逻辑。应用不再自动接管系统截图设置，也不启动未获授权的 Desktop 监听。用户通过 NSOpenPanel 选择截图/图片目录（最多三个），保存 security-scoped bookmark，在恢复访问后再恢复历史及启动 ScreenshotWatcher；过期书签刷新，无法恢复则给出重新选择入口。新增或移除目录要平衡资源访问生命周期。

应用私有目录只用于剪贴板历史，不被 ScreenshotWatcher 再次采集。用户选择的目录监听新图片及录屏，原件留在原处。文件导出使用 NSSavePanel，替换 Line.saveToDesktop 的直接路径写入；导出成功后仍保留历史，失败不丢内容。

### 公开 API 和商店分发

移除 FullScreen.swift 中 CGSMainConnectionID 和 CGSCopyManagedDisplaySpaces 私有调用。优先通过 NSWindow.collectionBehavior 的公开行为控制是否作为 fullScreenAuxiliary 进入全屏，不以屏幕录制权限或新的私有接口换取精确 Space 查询。验证普通桌面与原生全屏的实际行为，并在实现文档说明系统限制。

现有 Markup 服务使用硬编码服务名，需要核对其公开支持范围；商店版本可使用 Preview 或系统公开的共享服务选择入口，不依赖未公开的标注服务标识。Quick Look、录屏裁剪、Carbon 注册快捷键和登录启动需要在沙盒运行中验证，不能以编译通过替代验收。

移除指向 tendedero.app 的外部更新入口。建立 Xcode 工程/共享 Scheme，提供开发构建及商店 Archive/Export 路径；沙盒必须在开发验收中实际开启。通用二进制包含 Apple silicon 和 Intel。正式签名、描述文件及团队 ID 使用账号实际资料。

「关于」内提供隐私说明与许可。隐私说明描述本地剪贴板记录、目录授权、容量、删除方式、未标记敏感内容的限制，无账户、无分析、无开发者服务器上传。商店提交前需要真实可访问的隐私政策/支持页面 URL；不得虚构主体、邮箱或域名。PrivacyInfo.xcprivacy 根据最终使用的 required-reason API 填写并验证，不照搬无关声明。

## 验证计划

自动验证：文字和换行保真、容量及启动限制、重复条目、新旧索引恢复、隐私标记（包括混合项目）、自身复制过滤、输入大小边界、暂停期间异步回调、删除私有副本、外部原件保留。临时测试目录与独立偏好存储避免访问真实用户历史。

构建验证：Swift 测试、release 构建、git diff --check、plist/entitlements 检查、签名沙盒验证、二进制私有符号审计、资源中许可证及新图标核对。

桌面验证：中文、多行、长文、链接、图片；点击复制到文本编辑器；双击完整预览；超过一屏滚动；暂停/恢复；删除/清空；重启恢复；授权目录新截图及重启后新截图；普通桌面与全屏；错误授权或丢失目录。只用合成内容测试，不读取或展示用户现有敏感剪贴板。

## 发布所需的外部信息

实现和本机验证可以独立推进。正式上架需要确认可用开发者团队、Bundle ID、应用名可用性、价格/销售地区、真实支持与隐私页面、必要协议及税务状态；这些事实从账号实际状态或用户提供资料取得。认证挑战、不可代答的法律声明、商店最终提交动作若需用户参与，将在具体资料齐备后集中处理。
